**Scope:** Samsung S25 Ultra + S Pen → ExecuTorch scientific canary → PDB experimental proteins/ligands + separated ESM2 embedding proposals → Samsung XR visualization/sonification/haptics → mock hands-free protocol with human safety gates → append-only per-device event receipts and verified ordered Merkle/MMR checkpoints.

**Science ceiling:** ESM2 is an embedding model, not protein–drug folding evidence. A PDB crystal structure is measured structural evidence, not clinical efficacy. PPE detection is a camera suggestion, not a BSL-2 authorization or a safety guarantee. Cost savings require a prospective controlled study.

**Safety/privacy:** No restricted SPC, VCC, AI drug discovery, participant or lab datasets should enter this public repository without source-specific authorization. No video of actual lab participants without approval and consent.

Every PR must attach a reproducible Jupyter notebook, exact source and derived hashes, tested transformations, model weights/runtime/backend versions, an explicit result status, failed/negative test receipts and NEXT_ACTION.
