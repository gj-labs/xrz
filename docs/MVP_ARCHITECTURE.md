# MVP design and ownership

## Pipeline
Source URL/DOI/license/raw bytes → source manifest with SHA256 → separately addressable protein/residue/ligand/coordinate/citation/protocol atoms (content ID) → per-study/device occurrence ID and context → declared typed FCG edges → deterministic transformation+oracle → AI model proposal with inference receipt → human/independent challenge → per-step protocol decision → ordered MMR checkpoint → independent verification receipt → permissioned artifact and release review.

**Hash means identity, graph edge means declared relationship, Merkle means integrity/custody, not scientific truth or causation.** Corrections are successors; do not rewrite failures.

## Devices
- S25 Ultra: S Pen residue selection, real geometric reference, local model runtime, offline encrypted protocol event journal. LiquidAI GGUF via Ollama/llama.cpp is **not** an ExecuTorch `.pte` model. Export/test separately.
- Samsung XR: read-only/proposed scientific overlay, hands-free interactions, sonification/haptic mappings, visible HOLD/UNKNOWN state, spectator HDMI projection only after hardware testing. Zack leads this lane.
- Hosts: deterministic reproducible notebooks, model evaluation and independent custody checks. Never assert two independent scientific validators solely from two hosts.
- Vision: Meta vision models may **propose** PPE observations; the app must never grant entry or advance a safety-critical step without approved operator/site authorization.

## MVP acceptance and scientific case
Use **human carbonic anhydrase II**, not HET or PRNP. Reference RCSB **3HS4** (acetazolamide) and **4IWZ** (acetazolamide derivative), their experimental atomic coordinates and citations. Separate ESM-2 embeddings from ESMFold sequence fold predictions and from ligand pose/docking. Judge measurable outputs: exact source hashes, real coordinate geometry, correct HOLD decisions, event integrity, model backends/latency, error localization and recovery. *No claim that a drug folds correctly or works therapeutically based on ESM2.*

## Experiment gates
G0 — public source and license admission, raw hashes, reference notebook.
G1 — exact atom/occurrence and transformation identities, unit tests, independent MMR verifier.
G2 — actual S25 ExecuTorch model load, real device/ABI/backend, model/tokenizer hash, latency and repeat runs.
G3 — XR overlay and haptic/audio outputs measured, privacy controls, stage connectivity.
G4 — hands-free **mock** protocol with human-confirmed PPE and negative controls for skipped/deviant steps.
G5 — live event transfer acknowledgments, offline/reconnect replay, event tamper detected, reviewer-signoff.
G6 — publication/release rights, research claims limited to observed receipts, GitHub PR approvals.

All device, laboratory and financial savings gates presently **NOT_TESTED** in XRZ. No root or signing is claimed in this repository until independently verified.
